RESEARCH FILE / 01FINAL YEAR PROJECT · BUS303

抖音美妆直播促销话术
与短期 GMV 响应分析

以花西子官方旗舰店直播为研究场景，探索促销话术强度与短期 GMV 波动之间的关联，将分钟级数据连接到具体运营问题。

150有效分析样本
t + 3分钟级事件窗口
16.3–21.9%模型预测概率变化范围

EXPLORATORY RESULT / 预测概率约由 16.3% 升至 21.9%，为关联趋势，不构成因果结论。

01 / DATA

基于 DouChaCha 获取直播 GMV、观看人数等数据，将促销话术与分钟级直播数据进行时间对齐和分类编码，形成 150 个有效样本。

02 / METHOD

采用事件型观察研究设计，以话术为事件点，构建 t 至 t+3 分钟 GMV spike 指标，使用二元 Logistic Regression 分析话术强度与 spike 概率的关联。

03 / INSIGHT

探索性模型呈现正向关联趋势；结合统计结果与业务场景，提出围绕流量时机、优惠券及产品展示的直播运营优化建议。

美股金融数据分析
与投资策略研究

整合财务与股票收益数据，研究公司特征和收益表现之间的关系，从清洗、匹配到回归分析，形成有数据依据的策略建议。

29,266公司年度样本
19数据集变量
OLS回归分析方法

ACADEMIC RESEARCH / 策略建议用于展示研究思路，不代表已实现的投资收益。

01 / DATA

基于 WRDS 获取并合并 Compustat 财务数据与 CRSP 月度股票收益数据，完成清洗与匹配，构建 29,266 个公司年度样本、19 个变量的数据集。

02 / METHOD

使用 Python 开展 EDA 与 OLS 回归，分析 ROA、杠杆率、利润率、公司规模及收益波动率等因素，制作相关性矩阵、变量分布及年度收益趋势可视化。

03 / INSIGHT

结合统计分析和图表结果，形成基本面与价格动量相结合的投资策略建议。
