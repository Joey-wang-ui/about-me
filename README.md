## GitHub Pages

将本目录的文件提交到个人网站仓库的 `main` 分支。在 GitHub 仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支为 **main**，目录为 **/(root)**。

后续修改 `index.html` 并提交，GitHub Pages 会重新发布。首次部署完成后，以 Pages 设置中实际显示的网址为准。

`.nojekyll` 用于将此项目作为纯静态网站发布。
